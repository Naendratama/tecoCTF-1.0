# Teco CTF 2026

### **Tentang Event**

Lomba Cyber Security pada Ekstrakurikuler Technology Community (TECO) SMK Negeri 1 Pemalang akan dilaksanakan dalam format CTF (Capture The Flag). Peserta akan diberikan beberapa tantangan dengan berbagai kategori seperti Cryptography, Web Exploitation, Forensics, Reverse Engineering, dan Binary Exploitation. Setiap kategori memiliki tingkat kesulitan yang beragam, dan peserta diharapkan menyelesaikan tantangan untuk mendapatkan “flag” yang nantinya disubmit untuk mendapatkan poin.
